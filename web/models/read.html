Read model

Textförståelse

Read-modellen plockar ut varje paragraf, fotnot och tabell som styr era ansökningar.

Modellen kombinerar OCR och naturlig språkförståelse för att tolka inskannade PDF:er, bifogade Word-filer och signerade avtal. Resultatet ger Funding Assistant möjlighet att svara med exakta citat.

Tillbaka till assistenten Visa Read release notes
Noggrannhet 99.1% Tecken- och tabellprecision på testade myndighetsdokument.
Format PDF, DOCX Stöd för både uppladdade mallar och skannade kopior.
Språk 25+ Tränad på svenska, engelska och de vanligaste EU-språken.

Nyckelkapabiliteter

Citerbar OCR

Mappar varje textbit till sin sidposition så att assistenten kan skapa hänvisningar med paragraf, sida och rad.

Tabellavkodning

Identifierar rad- och kolumnrubriker även i komplexa finansieringsmatriser.

Entity tagging

Markerar budgetposter, datum, myndigheter och juridiska termer för att förenkla filtrering.

RAG-optimerad struktur

Delar upp dokument i chunkar anpassade för retrieval-modeller så att svaren blir träffsäkra.

Exempelutdrag

JSON-output

{
  "document": "Clean Energy District Grant Guide.pdf",
  "page": 12,
  "paragraph": "Applicants must secure a municipal resolution confirming net-zero alignment prior to submission.",
  "citations": [
    {
      "type": "section",
      "value": "2.1"
    }
  ],
  "entities": ["municipal resolution", "net-zero alignment"]
}

Utdraget ovan visas i Funding Assistant när användaren ber om bekräftelse på krav och bilagor.
