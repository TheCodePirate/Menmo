Strukturbevarande tolkning

Layout-modellen återskapar dokumentets arkitektur för att bevara kontexten.

Den används när ansökningar, ritningar eller miljörapporter behöver bibehålla visuell hierarki. Funding Assistant kan därför hänvisa till specifika tabeller, figurer och bilagor.

Tillbaka till katalogen Layout release notes
Bevarad struktur 98% Sidlayout och rubriknivåer bibehålls i exporterna.
Format PDF, TIFF Fungerar med komplexa ritningar och inskannade blanketter.
Stödfunktioner Tables, charts Identifierar diagram, bilder och fotnoter som separata objekt.

Kapabiliteter

Layout-uppmärkning

Detekterar rubriker, brödtext, figurer och bilagor för att bevara dokumentets logiska struktur.

Avancerad figuridentifiering

Identifierar diagram, kartor och ritningar så att assistenten kan länka direkt till visuella bevis.

Anchor points

Skapar koordinater per element vilket gör att svar kan länka till exakt position i PDF-viewer.

Hybrid indexering

Kombinerar text och layoutdata för att stödja sökningar som “visa tabell på sidan 32”.

Visuell återgivning

Exempel

Miljörapport 2024 — Layout-modellen identifierar figur 4.2 “Projected Emissions Reduction” och gör den sökbar. Funding Assistant kan därför jämföra siffror mot projektmål och referera till bilden i chatten.

Användningsfall

Hållbarhetsrapporter

Bevara diagram och KPI-tabeller för att länka tillbaka när styrelsen granskar ESG-utfall.

Tekniska bilagor

Underlätta för tekniker att hitta rätt ritning eller planritning under ansökningsprocessen.

Revision

Visa exakt var i dokumentet en viss bestämmelse eller tabell finns när revisorer begär bevis.
