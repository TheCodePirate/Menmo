# Menmo Experience Cloud Command Center

A modern executive workspace inspired by Oracle Redwood design principles. The Menmo Experience Cloud Command Center unifies sales, service, and customer experience telemetry into a single responsive page built with vanilla HTML, CSS, and JavaScript.

## Features

- **Strategic metric tiles** with sparklines and responsive trend states across weekly, monthly, and quarterly views.
- **Interactive engagement pulse chart** that compares Menmo performance with Redwood benchmarks across NPS and activation journeys.
- **Revenue motions table** with segment filtering and accessible health indicators.
- **Operational sidebar** showcasing rhythm-of-business milestones, rapid action cards, and AI-highlighted insights.
- **Adaptive layout** featuring collapsible navigation, theme switching, and mobile-first responsiveness.

## Getting started

No build tools are required. Open the `index.html` file in any modern browser to explore the experience. For local development with live reload, you can serve the folder with your preferred static file server. Example using Python:

```bash
python -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in the browser.
